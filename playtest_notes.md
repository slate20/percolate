# Playtest Notes

## Bugs/Fixes

- Vague text under roasting, eg "Medium Green" "Medium Brown" "Medium Yellow" "Medium Dark". Color label not meant to be shown?
- Menu/UI navigation is a bit clunky. Mouse interaction is fine but keyboard interaction is not as intuitive as it should be. Tab switching between elements is "Textual" domain knowledge, but not immediatly obvious to players who are non-devs. Pressing enter also makes the highlighted item un-highlight. Pressing an arrow key brings the highlight back, but again not obvious to an average player.
- Header on each screen needs to be labeled appropriately. Farm and Roasting Screens have no lable or tect, Market shows 'Percolate - <gold>g'. This should be changed to the name Screen: Farm, Roasting, Market. The upgrade modals also need to inlcude the players gold count somewhere (their own Header-adjacent element)
