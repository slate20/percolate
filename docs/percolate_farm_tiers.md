# Percolate ASCII Farm Tiers

## Canvas
Fixed canvas of 80x20. Rows 1-5 reserverd for skybox/sun. Remaining rows for building slots

## Building Sections

Moving from left to right:
- **Farmhouse section**: col 1-32
- **Storage shed section**: col 33-50
- **Barn/Roastery section**: col 51-80

## Farmhouse Tiers
Scales as Storage Shed and Barn/Roastery increase in tiers. For now, if Roastery Barn == Tier 2 and Storage Shed >= Tier 3, then the house upgrades to Tier 2.

## Storage Shed Tiers
Scales with plot upgrades. Plot upgrades will become:

- First upgrade = +1 plot (4 total) and Tier 2 shed
- Second upgrade = +2 plots (6 total) and Tier 3 shed
- Third upgrade = +2 plots (8 total) and Tier 4 shed
